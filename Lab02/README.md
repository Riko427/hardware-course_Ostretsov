## «Ответы на контрольные вопросы»
1. Что такое IL и зачем он нужен между C# и машинным кодом?

IL-код — промежуточный код, который нужен чтобы  отделить исходный код от конкретной архитектуры процессора, что позволяет запустить его на разных процессорах.

2.  Почему .dll можно декомпилировать?

Сборка .NET содержит IL и метаданные, поэтому её часто можно 
декомпилировать в код, похожий на исходный.

3.  Какие отличия Debug и Release вы увидели в IL?

В Release меньше кода, за счёт удаления средств отладки.

4.  Почему Release обычно быстрее Debug?

Ответ был дан в 3-ем вопросе.

5.  Почему строковый пароль в .dll нельзя считать защищённым?

dll можно декомпелировать.
