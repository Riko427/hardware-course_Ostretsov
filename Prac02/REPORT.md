    Часть 1.

| Что сравниваем                        | Совпадает с оригиналом | Отличается                                       |
| ------------------------------------- | ---------------------- | ------------------------------------------------ |
| Имена переменных                      | Да, полностью          |                                                  |
| Строковые литералы (текст в кавычках) | Да, полностью          |                                                  |
| Структура кода (класс, метод)         |                        | Отличается - При декомпиляции добавились строки: private static void <Main>$(string[] args){(Исходный код)} |

Код похож и является его копией.

    Часть 2.

| Что было в исходном C# | Что вы нашли в IL |
| ---------------------- | ----------------- |
| строковый литерал (текст в кавычках) | ldstr "Hello, World!" |
| вызов метода (например, Console.WriteLine(...)) | call void [System.Console]System.Console::WriteLine(string) |
| завершение метода  | nop |

Не похож на C#. Больше похоже на список примитивных действий.
