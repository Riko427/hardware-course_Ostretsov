## Исследование 1. Что находится внутри int

int number = 1

01-00-00-00

int number = 256

00-01-00-00

int number = 65536

00-00-01-00

1. Почему число 1 занимает 4 байта, хотя для его записи достаточно одного байта?

Под тип данных int выделено 4 байта памяти.

2. Что изменяется в байтовом представлении числа 256?

Значение числа и набор байтов.

3. Почему число 65536 уже требует другого набора байтов?

Оно записано определённым набором байтов.

## Исследование 2. Почему порядок байтов имеет значение
BitConverter.IsLittleEndian = True

Байты числа: 78-56-34-12

Младший байт хранится первым.
## Исследование 3. Число и текст
"ABC" --> 41-42-43

"Привет" --> D0-9F-D1-80-D0-B8-D0-B2-D0-B5-D1-82

Здесь можно заметить, что количество символов и байтов могут отличатся. Это происходит потому что представление "русских символов" закодировано несколькими байтами, а не одним.

## Исследование 5. Обратное преобразование
Почему для обратного преобразования нужно снова указать UTF-8?

Для того чтобы программа правильно перевела байты в текст.
