## Переполнение
Предположение: при исполнении операции "int.MaxValue + 1", программа завершится с ошибкой.

Результат: программа вывела отрицательное число.

Предположение: при исполнении операции "int.MinValue + 1", программа выведет положительное число.

Результат: программа вывела положительное число.

int.MaxValue + 1  →  int.MinValue

int.MinValue - 1  →  int.MaxValue

Когда результат операции выходит за диапазон значение типа int, он записывается неправильно и выходит, что значение из максимального становится минимальным и наоборот.

max: FFFFFF7F

overflowed: 00000080
## Текстовое представление
Предположение: для "Hello" количество символов и байтов 
совпадёт, а для "Привет" разница будет наибольшей.

| Текст | Количество символов | Количество UTF-8 байтов |
| :--- | :--- | :--- |
| Hello | 5 | 5 |
| Привет | 6 | 12 |
| � | 1 | 3 |

Один символ может занимать несколько байтов так как в таблице UTF-8 у каждого символа есть номер, который может занимать несколько байтов.
